## 📖 About The Project
**Glowora** is a high-end, visually appealing e-commerce frontend designed specifically for the skincare and beauty industry. Built with a focus on UI/UX, this project features a soft pastel aesthetic, smooth micro-interactions, and a fully responsive layout tailored to provide a luxurious browsing experience.

This project serves as a professional portfolio piece demonstrating modern web development practices using the React ecosystem.

## ✨ Key Features
- **Modern Component Architecture:** Built entirely with reusable React functional components.
- **Premium UI/UX:** Features a split-hero layout, glassmorphism navigation, and elegant typography (Playfair Display + Poppins).
- **Advanced Styling:** Utilizes Tailwind CSS for utility-first styling, custom brand color palettes, and complex gradient overlays.
- **Smooth Animations:** Custom CSS keyframe animations for fade-in effects and floating hover states to make the UI feel alive.
- **Fully Responsive:** Carefully crafted media queries ensuring pixel-perfect layouts across Mobile, Tablet, and Desktop devices.
- **Blurred Background Aesthetics:** Implements background images with soft blur and gradient overlays for a premium feel.

## 🛠️ Tech Stack & Tools
- **Core:** [React.js](https://reactjs.org/) (v18+)
- **Build Tool:** [Vite](https://vitejs.dev/) (For lightning-fast HMR and optimized builds)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/) (Feather Icons)
- **Fonts:** Google Fonts (Playfair Display, Poppins)
- **Version Control:** Git & GitHub
